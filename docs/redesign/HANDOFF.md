### 3b. Tech feasibility (verified against npm registry + local node_modules on 2026-09-03)
- **Architecture pick:** GSAP 3 ScrollTrigger (free incl. all plugins since Apr 2025) + `@gsap/react` `useGSAP` (StrictMode-safe cleanup) driving an R3F `<Canvas>` pinned with CSS `position: sticky; top:0; height:100vh` inside tall sections; normal DOM sections between. Per section: `ScrollTrigger.create({trigger, start:'top top', end:'bottom bottom', scrub:0.5, onUpdate: s => progress.current = s.progress})`; read `progress.current` in `useFrame`. **Never setState per tick. Don't GSAP-`pin` the canvas (WebGL flicker). Call `ScrollTrigger.refresh()` after fonts/images load.** `gsap.matchMedia({reduceMotion:'(prefers-reduced-motion: reduce)'})` for a11y branches. Lenis (5.4 KB gz, native-scroll based, honours reduced motion) only if scrub isn't smooth enough.
- **Rejected:** drei `ScrollControls` (own scroll container in front of canvas; fights ScrollTrigger; iOS bug). framer-motion `useScroll` as main engine (OK for a single hero only). WebGPU/TSL: three side stable but R3F first-class support is only in `@react-three/fiber@10.0.0-alpha` + `drei@11 alpha` (need three ≥0.185); drei partly broken on WebGPU; `postprocessing` WebGL-only → **stay WebGL, keep GLSL small**. Theatre.js dormant (last release 2024-05). Rive optional for HUD; DOM/SVG + framer-motion is 0 KB.
- **Packages to add:** `gsap@3.15.0`, `@gsap/react@2.1.2`, `urdf-loader@0.13.1` (optional if robots baked to GLB); optional `lenis@1.3.26`; skip `@react-three/postprocessing` (bloom = 109 KB gz; additive emissive points instead). Bump `@react-three/fiber` → 9.7.0, `@react-three/drei` → 10.7.8. Keep `three@0.184.0`. **Remove** `@splinetool/react-spline` + `@splinetool/runtime` after hero swap (runtime = 1.43 MB gz vs 259 KB gz for three+R3F+drei subset).
- **urdf-loader 0.13.1:** Apache-2.0, ESM, works with three r184 via `useLoader(URDFLoader, url, l => {...})`. Default mesh loader handles only `.stl`/`.dae`; for GLB set `l.loadMeshCb = (path, manager, material, done) => ...` (0.13.0 added the `material` arg). `l.packages = { pkg: `${BASE}/robots/pkg` }` to resolve `package://`. URDF is Z-up → `<primitive rotation={[-Math.PI/2,0,0]}>`. Joints: `robot.joints['FL_hip_joint'].setJointValue(rad)`; limits in `joint.limit.lower/upper`. **basePath gotcha:** Next prefixes only Link/Image/router, never `fetch`/loaders → always prefix asset URLs with `/my-portfolio` manually (put it in one constant). Ponytail alternative: bake robot into one GLB with named joint nodes and rotate nodes via `useGLTF` → no loader.
- **Point clouds (50k–500k):** `THREE.Points` + custom `ShaderMaterial`, one draw call; static positions, animate via uniforms (`uTime`, `uSweep`, `uAngle`); LOD via `geometry.setDrawRange(0,n)` (100–200k on mobile). Sweep recipes: plane `d = dot(pos,uDir)-uSweep; band = 1-smoothstep(0,w,abs(d)); if(d>0) discard;`; rotating beam `da = mod(atan(z,x)-uAngle, TAU); alpha = exp(-da*k)`; per-point `aRand < uProgress` reveal. `gl_PointSize` max 64 px on Apple GPUs.
- **Loading/perf:** `next/dynamic(() => import(...), {ssr:false, loading: Poster})` inside a `'use client'` file (current `components/ui/spline-scene.tsx` uses React.lazy — replace). Ship a real `<img>` poster in prerendered HTML (canvas is never an LCP candidate). `dpr={[1,1.5]}`, `<PerformanceMonitor onDecline>`/`<AdaptiveDpr>`, `useDetectGPU()` tier-0 → static fallback, `antialias:false`, `frameloop="demand"` + `invalidate()` from ScrollTrigger `onUpdate` (switch to `always` only while world in view), `aria-hidden` on canvas. glTF: `npx @gltf-transform/cli@4.5.0 optimize in.glb out.glb --compress draco --texture-compress webp`; drei `useGLTF` decodes Draco (self-host decoder: `useGLTF.setDecoderPath('/my-portfolio/draco/')`) and Meshopt; `useGLTF.preload()` + `<Preload all/>`. Next 16 static export: `dynamic` route config coerced to `'error'`; Turbopack default.
